## [0.1.0](https://github.com/Fredehagelund92/footnote/compare/v0.1.0...v0.1.0) (2026-11-28)


###   BREAKING CHANGES

* metrics are named footnote_*, the command line is npm run footnote, the image keeps its keys in /var/lib/footnote, edition exports say footnote.edition/1, and the compose project, service and volumes are named footnote (docs/operations.md, "Upgrade from Heed 0.1").
* **mcp:** the MCP server no longer offers get_facts, find_facts, search_facts, search_context, read_item, report_gap, give_feedback or draft_context. Use get_context, find_context, read_context, report and suggest_context, which take the agent contract's arguments and replies.
